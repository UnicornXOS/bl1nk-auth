Versatile button with 6 variants and 8 sizes. Use for any interactive action.

```jsx
<Button>Save</Button>
<Button variant="outline" size="sm">Cancel</Button>
<Button variant="ghost" size="icon"><PlusIcon /></Button>
<Button variant="destructive">Delete</Button>
<Button variant="link">Learn more</Button>
```

**Variants:** `default` (emerald fill) · `outline` (bordered) · `secondary` (muted fill) · `ghost` (transparent) · `destructive` (red tint) · `link` (text only)
**Sizes:** `xs` h-24px · `sm` h-28px · `default` h-32px · `lg` h-36px · `icon` 32×32 · `icon-xs/sm/lg`
**States:** hover (brightness/bg), active (translateY 1px), disabled (opacity-50, pointer-events-none)

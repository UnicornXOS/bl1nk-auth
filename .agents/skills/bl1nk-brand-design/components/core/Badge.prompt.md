Compact status label. Use for tags, counts, statuses, and labels.

```jsx
<Badge>New</Badge>
<Badge variant="secondary">Beta</Badge>
<Badge variant="destructive">Error</Badge>
<Badge variant="outline">Draft</Badge>
```

**Variants:** `default` (emerald fill) · `secondary` (muted) · `destructive` (red tint) · `outline` (bordered)
